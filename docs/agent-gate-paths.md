# Agent Gate Paths — fonte declarativa única

Conteúdo derivado exclusivamente de [agent-bridge-design.md](agent-bridge-design.md) (§5.1, §5.2,
§5.3). É lido pelo GPT ao escrever HANDOFFs, pelo humano/bridge na checagem mecânica (pré-despacho e
pós-execução) e por Claude Code durante EXECUTE. Nenhuma regra de gate é repetida em outro lugar;
alterar este arquivo é sempre decisão humana. Classes (design §5.1): **A** = HARD HUMAN GATE,
**B** = CONDITIONAL HUMAN GATE, **C** = MECHANICAL GUARD. As definições dos gates estão em
[agent-execution-protocol.md](agent-execution-protocol.md).

Notação: `glob` = padrão (`**` = qualquer profundidade); `exato` = um único caminho; `—` = o gate não
é detectado por caminho ou comando (detecção por conteúdo, pelo executor, ou ação humana fora do loop).
